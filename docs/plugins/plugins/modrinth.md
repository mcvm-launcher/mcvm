# Modrinth
ID: `modrinth`

The Modrinth plugin will add the `modrinth` package repository, allowing you to install Modrinth projects and modpacks as packages on your instances and templates.

## Usage
Browse packages under the Modrinth repository or add them manually in your config by putting `modrinth:` before the package ID.

### Modpack Format
The `mrpack` transfer format will be added, letting you import Modrinth modpacks easily. See [Importing and Exporting](../../instance_transfer.md).
