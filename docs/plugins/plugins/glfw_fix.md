# GLFW Fix
ID: `glfw_fix`

The GLFW Fix plugin fixes memory errors and crashes when starting the game with mods. It does this by downloading a newer version of GLFW and applying it to the instance.

## Usage

+++ App
To enable the fix on an instance or template, set `Fix GLFW` to true in the `Plugins` tab of that item's configuration.
+++ CLI
To enable the fix on an instance or template, set `"fix_glfw"` to true on that instance or template in your config.
+++
