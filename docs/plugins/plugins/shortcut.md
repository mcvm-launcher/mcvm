# Shortcut
ID: `shortcut`

The Shortcut plugin can be used to create desktop shortcuts for launching instances.

## Usage
+++ App
Go to the instance's page and click the `More` button to bring up the dropdown. Click `Create Shortcut` and it will be created on your desktop.
+++ CLI
Use the `nitro instance shortcut` command to create a shortcut for an instance. You can specify a custom name for the shortcut with --name or a specific account to launch it with using --account.
+++
