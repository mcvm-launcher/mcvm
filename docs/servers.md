# Setting up a Server

Server instances in Nitrolaunch are extremely simple.

!!!info Note
By launching a server, you agree to Mojang's End User License Agreement.
!!!

## Creating the Server

Simply create an instance like you normally would, but with the `server` type instead of `client`.

## Letting People Connect

When you launch a server locally, you need either a proxy or port forwarding to let others connect to your server. Make sure your firewall is configured for port `25565`. Playit.gg support is also coming soon to make this process simpler.
